# AZ-305 Solutions Architect Expert Study Repository

This repository contains AZ-305 study notes and hands-on lab content organized by the four official exam domains.

## Exam Domains

| Domain | Weight | Folder |
|---|---:|---|
| Design infrastructure solutions | 30-35% | [Design Infrastructure Solutions](./Design%20infrastructure%20solutions/) |
| Design identity, governance, and monitoring solutions | 25-30% | [Design Identity, Governance, and Monitoring Solutions](./Design%20identity,%20governance,%20and%20monitoring%20solutions/) |
| Design data storage solutions | 20-25% | [Design Data Storage Solutions](./Design%20Data%20Storage%20Solutions/) |
| Design business continuity solutions | 15-20% | [Design Business Continuity Solutions](./Design%20business%20continuity%20solutions/) |

## Repository Structure

- Domain-level `README.md` files contain overviews, decision guidance, and study references.
- Domain folders include topic markdown files for core concepts and architecture tradeoffs.
- `Labs/` folders contain practical lab exercises and validation activities.

## How to Use This Repo

1. Start with a domain `README.md` to review key services and decision points.
2. Study the related topic files in that domain.
3. Complete the labs to apply concepts in realistic scenarios.
